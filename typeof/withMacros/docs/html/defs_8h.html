Finds the maximum element from the vector v of size n.

The statement at line 24 basically determines the type of an element of the given vector v and then declares a pointer of that type named _v. Note that the expression is typeof((v)[0]) and not typeof(v[0]) because v could be an expression performing pointer arithmetic as well.
