\doxysubsection{Detailed Description}
An example demonstrating the working of the {\ttfamily offsetof} macro. 

The {\ttfamily offsetof} macro in C basically returns the offset of a structure member from the beginning of that structure.

Here, the {\ttfamily size\+\_\+t} is an unsigned integer type used for a count of bytes. So, the following line\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keywordtype}{unsigned}\ \textcolor{keywordtype}{int}\ offset\ =\ (size\_t)\ \&((\mbox{\hyperlink{structSample}{Sample}}*)NULL)-\/>d;}

\end{DoxyCode}
 actually returns the offset of the field {\ttfamily d} from the beginning of {\ttfamily \doxylink{structSample}{Sample}} in bytes.

The above line has been explored in details in the given example programs.

The above line can also be written like this\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keywordtype}{unsigned}\ \textcolor{keywordtype}{int}\ offset\ =\ (size\_t)\ \&((\mbox{\hyperlink{structSample}{Sample}}*)0)-\/>d;}

\end{DoxyCode}
 They both mean the same. See \href{https://stackoverflow.com/a/13723512}{\texttt{here}}.
