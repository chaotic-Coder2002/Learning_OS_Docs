In the line unsigned int offset = (size_t) &s->d, the -> operator is not used to access the value of the field d, it's instead used to access its address. So, here we cannot say that the we are dereferencing the Sample pointer s. So, since no dereferencing is happening here, the following lines are valid as well:

Sample *s2 = NULL;
double *dptr = &s2->d;

Now, if s2 is NULL, then how do we get an address of its field d ? I think this could be the answer to that question.

#include<stdio.h>
#include<stdlib.h>
#include "defs.h"
int main(int argc, char *argv[]) {
Sample *s = malloc(sizeof(Sample));
unsigned int offset = (size_t) &s->d;
printf("%u\n", offset);
double *dptr = &s->d;
printf("%p\n", dptr);
Sample *s2 = NULL;
offset = (size_t) &s2->d;
printf("%u\n", offset);
double *dptr2 = &s2->d;
printf("%p\n", dptr2);
free(s);
return 0;
}
