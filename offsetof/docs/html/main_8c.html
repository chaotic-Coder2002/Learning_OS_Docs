Detailed Description

An example demonstrating the working of the offsetof macro.

The offsetof macro in C basically returns the offset of a structure member from the beginning of that structure.

Here, the size_t is an unsigned integer type used for a count of bytes. So, the following line:

unsigned int offset = (size_t) &((Sample*)NULL)->d;

actually returns the offset of the field d from the beginning of Sample in bytes.

The above line has been explored in details in the given example programs.

The above line can also be written like this:

unsigned int offset = (size_t) &((Sample*)0)->d;

They both mean the same. See here.
