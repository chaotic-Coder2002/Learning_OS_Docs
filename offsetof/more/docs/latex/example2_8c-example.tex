The structure {\ttfamily \doxylink{structSample}{Sample}\+:}

 contains two integers, {\ttfamily 4} bytes each.~\newline
{\bfseries{Note\+:}} The base address of a structure is actually the address of the first byte of the structure.

The statement {\ttfamily printf("{}\%p\textbackslash{}n"{}, \&((Sample\texorpdfstring{$\ast$}{*})0)-\/\texorpdfstring{$>$}{>}b);} basically prints the address of {\ttfamily b}. This will be {\ttfamily 0x4} or 4 bytes (structure padding), because {\ttfamily b} is {\ttfamily 4} bytes away from the base address, if {\ttfamily 0} is considered as the base address.~\newline
 The next statement {\ttfamily printf("{}\%p\textbackslash{}n"{}, \&((Sample\texorpdfstring{$\ast$}{*})1)-\/\texorpdfstring{$>$}{>}b);} also prints the address of {\ttfamily b}. But this time, it will be {\ttfamily 0x5} or 5 bytes, because again, {\ttfamily b} is 4 bytes away from the base address, so its address is calculated as {\ttfamily (1 + 4) bytes}.
