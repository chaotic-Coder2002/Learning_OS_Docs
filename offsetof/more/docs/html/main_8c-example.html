This program demonstrates how to get to the address of the parent struct using the struct nested inside it.

First, we are assigning the address of birdNest to nestedStruct by typecasting its address into an array of bytes:

char *nestedStruct = (char*) &aTree.birdNest;

The reason why we are typecasting to char* is that in C, a char is 1 byte and a char* points to an array of 1 bytes and the offset that will get for birdNest from the base address of the struct Tree will also be in bytes, so performing pointer arithmetic on the offset will actually give us the correct result.

Now, the line:

Tree *temp = (Tree*)(nestedStruct - (size_t) &((Tree*)0)->birdNest);

Let's first focus on the second part of the line i.e.

&((Tree*)0)->birdNest;

Here, &((Tree*)0)->birdNest basically gives the address of birdNest relative to 0. This address is then typecast to bytes by the size_t type.

After that the the usual pointer arithmetic is performed. Let's say for example &((Tree*)0)->birdNest gave the address of birdNest to be 0x8 (which is 8 in decimal), then typecasting it to a size_t type will give us an 8 which is actually 8 bytes. So, the statement Tree* temp = (Tree*)(nestedStruct - (size_t) &((Tree*)0)->birdNest); in this case will be simplified to: Tree* temp = (Tree*)(nestedStruct - 8);, which is regular pointer arithmetic in C.

Now, let's understand this with an example, consider that we have a char array of 10 characters. For simplicity, let's use decimal numbers as addresses of each element. Since there are 10 elements in the array, so let's say that the starting address is 1001 and let's say that there is an element at address 1005 and we have set a pointer pointing to that address. Now, we want the pointer to point to the address 1001. We can see that the address 1005 is 4 bytes away from 1001. So, now, all we have to do is subtract 4 from the address 1005 and we will get to the starting/base address of the array. Let's assume that p is the pointer pointing to address 1005, so in order for p to point to 1001, we will do: p = p - 4 and that way p will finally point to 1001.

#include<stdio.h>
#include "defs.h"
int main(int argc, char* argv[]) {
Tree aTree = {"Mango", {5, 2}};
printf("sizeof(Nest): %zu\n", sizeof(Nest));
printf("sizeof(Tree): %zu\n", sizeof(aTree));
char* nestedStruct = (char*) &aTree.birdNest;
Tree *temp = (Tree*)(nestedStruct - (size_t) &((Tree*)0)->birdNest);
printf("sizeof(*temp): %zu\n", sizeof(*temp));
return 0;
}
