This is an example demonstrating the concept of finding the offset relative to a number.

The structure Sample:

typedef struct Sample {
int a;
int b;
} Sample;
Sample
Definition example2.c:3

contains two integers, 4 bytes each.
Note: The base address of a structure is actually the address of the first byte of the structure.

The statement printf("%p\n", &((Sample*)0)->b); basically prints the address of b. This will be 0x4 or 4 bytes (structure padding), because b is 4 bytes away from the base address, if 0 is considered as the base address.
The next statement printf("%p\n", &((Sample*)1)->b); also prints the address of b. But this time, it will be 0x5 or 5 bytes, because again, b is 4 bytes away from the base address, so its address is calculated as (1 + 4) bytes.

#include<stdio.h>
typedef struct Sample {
int a;
int b;
} Sample;
int main(int argc, char* argv[]) {
printf("%zu\n", (size_t) &((Sample*)0)->b);
printf("%p\n", &((Sample*)0)->b);
printf("%zu\n", (size_t) &((Sample*)1)->b);
printf("%p\n", &((Sample*)1)->b);
return 0;
}
